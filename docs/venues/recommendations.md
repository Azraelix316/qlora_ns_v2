# Recommended Publication Venues (D5 Compliant)

This document provides a consolidated shortlist of publication venues, strictly following the **D5 operative ordering** established in `state/reviewer/DECISIONS.md`. 

The priority is placed on Scientific Computing and Physics journals/conferences (scicomp/physics framing), followed by high-impact Machine Learning conferences. All AISTATS, ICASSP, and DFD targets have been excluded per the D5 decision.

## Accessibility & Location Notes
* **Virtual/Hybrid Preference:** For researchers in Taiwan/Asia, venues with strong hybrid options or purely virtual submission processes are prioritized to minimize travel burden.
* **Time Zones:** When attending conferences, please account for time zone differences (typically UTC+8).
* **Rolling Journals:** Submission is open year-round; no specific deadline applies.
